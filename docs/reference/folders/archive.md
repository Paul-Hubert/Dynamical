## Summary
Code kept for reference and not compiled (CMake only globs `src/`). `archive/tilemap/` holds the previous 2D tile-map simulation: tile-map rendering, heightmap/tile world (`MapManager`, `MapGenerator`), SPH particles, sprite objects, tile-map AI and gameplay, top-down camera, all on the EnTT 3.8 API and `Position` components. Its `README.md` maps the files to their original `src/` paths and explains how to port a part back.
