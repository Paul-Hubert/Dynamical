| 2026-10-31 | P0 | `RunArgs` adds `capture_dir` (where captures go, default `captures`) and `ticks` also applies to `dynamical` (exit after N frames, used by probe runs) | The capture keys in architecture.md have no output location; a probe run needs an end | Write next to the script; a probe-specific `probe_frames` key |
| 2026-10-31 | P0 | `fixed_frame_dt > 0` is the single "deterministic run" switch: synchronous chunk generation, no collider prefetch, frame-clock grass time, fixed ImGui delta, zeroed wall-clock timings in the debug menu. `capture` and `probe` default it to 1/60 and hide the window; both force 960 × 540, windowed, `vr_mode=0` (not saved) | Probes need the same determinism as captures (S0.1); the debug menu prints wall-clock step times | Separate flags per source |
| 2026-10-31 | P0 | The probe dumps every entity holding `Transform` + `RigidBody`, ordered by entity id; `index` is the rank. | 2026-10-31 | P0 | `S0.1` (and later `S1.1`) carry the CTest label `gpu`, not `scenario` | Until P1, `base` only runs inside `dynamical`, which needs a Vulkan device and window; CI runs `unit|scenario|protocol` without a GPU | Label `scenario` and skip in CI |
| 2026-10-31 | P0 | vcpkg manifest gets a default feature `viewer` (sdl2, openxr-loader, tinygltf, vulkan); the `ci` preset sets `VCPKG_MANIFEST_NO_DEFAULT_FEATURES=ON` and builds in `build/ci` | CI must not need graphics packages; one manifest, no baseline change | Install everything in CI |
