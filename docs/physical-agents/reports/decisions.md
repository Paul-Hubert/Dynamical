# Decision log (autonomous run P0 → P3)

Choices made without a human, with the reason and the alternatives. Newest last.

| Date | Phase | Decision | Why | Alternatives |
|---|---|---|---|---|
| 2026-10-31 | P0 | Until P1 splits the library, `dynamical_tests` links only the sources that build without Vulkan (`util/log`, `scene/run_args`, the `imgdiff` core), not every existing source | Linking the whole tree would pull `main()`, Vulkan, SDL and OpenXR into the tests; step 9 already restricts CI to the non-Vulkan files | Link every source with `main` excluded (needs the Vulkan SDK in CI) |
| 2026-10-31 | P0 | `RunArgs` adds `capture_dir` (where captures go, default `captures`) and `ticks` also applies to `dynamical` (exit after N frames, used by probe runs) | The capture keys in architecture.md have no output location; a probe run needs an end | Write next to the script; a probe-specific `probe_frames` key |
| 2026-10-31 | P0 | `fixed_frame_dt > 0` is the single "deterministic run" switch: synchronous chunk generation, no collider prefetch, frame-clock grass time, fixed ImGui delta, zeroed wall-clock timings in the debug menu. `capture` and `probe` default it to 1/60 and hide the window; both force 960 × 540, windowed, `vr_mode=0` (not saved) | Probes need the same determinism as captures (S0.1); the debug menu prints wall-clock step times | Separate flags per source |
| 2026-10-31 | P0 | The probe dumps every entity holding `Transform` + `RigidBody`, ordered by entity id; `index` is the rank. On master that is exactly the 12 ring boxes (the lineup folder only holds `box.gltf`, VR hands only exist with a headset) | Rank is stable across the P1 port as long as creation order is kept; entity ids are compared too | Filter on box size; tag entities |
| 2026-10-31 | P0 | `S0.1` (and later `S1.1`) carry the CTest label `gpu`, not `scenario` | Until P1, `base` only runs inside `dynamical`, which needs a Vulkan device and window; CI runs `unit|scenario|protocol` without a GPU | Label `scenario` and skip in CI |
| 2026-10-31 | P0 | vcpkg manifest gets a default feature `viewer` (sdl2, openxr-loader, tinygltf, vulkan); the `ci` preset sets `VCPKG_MANIFEST_NO_DEFAULT_FEATURES=ON` and builds in `build/ci` | CI must not need graphics packages; one manifest, no baseline change | Install everything in CI |
| 2026-10-31 | P0 | CI's vcpkg binary cache uses the `files` provider stored with `actions/cache` | vcpkg removed the `x-gha` provider; this keeps the cache inside GitHub Actions as architecture.md intends | NuGet on GitHub Packages (needs a token) |
| 2026-10-31 | P0 | `build/venv` is a venv of Python 3.10.12 taken from the existing conda env `env` (read-only use of its interpreter) | The fork's `ml-agents` requires Python 3.10.1–3.10.12; the system Python is 3.13 | A conda prefix env in `build/venv` |
| 2026-10-31 | P1 | Host system lists merge by concatenation in include order, then **each system keeps its last position**: a scene may list a system an include already provides to place it (`base` lists `Input, UI, Time, PlayerControl, …` after `common/desktop.json`) | T1.5 requires master's exact order (Time and VRControl sit between desktop systems), and desktop.json must still be included | Anchors such as `"after": "UI"`; dropping desktop.json from `base` |
| 2026-10-31 | P1 | Scene JSON: comments allowed; a string that is exactly `${x}` keeps x's type, other `${x}` are interpolated as text; a string matching `<file>.json#<key>` (after substitution) reads the value from `resources/<file>` (`<key>` a top-level name or a JSON pointer); the resolved dump carries `resolved_from { scene, includes }` so it reloads to the same resolved JSON | scenes.md leaves these mechanics open | Explicit `{"$ref": …}` objects |
| 2026-10-31 | P1 | `Settings` stays in the library (cereal is a library dependency in architecture.md) but only `dynamical` constructs it; `ChunkManagerSys` falls back to `Settings::default_view_distance` (768) when no `Settings` exists | Keeps master's debug-menu slider working unchanged | Move `Settings` to the viewer and add a library-side view-distance context variable |
| 2026-10-31 | P1 | All view-only sources physically move under `src/view/` (game, spawn, the master systems and `input.h`, `model_renderable.h`, `time.h`); the library is exactly `src/{logic,physics,scene,util}` | The header-boundary test (T1.1) then scans whole directories; no exclusion list to drift | architecture.md's `list(FILTER … EXCLUDE)` with files left in `src/logic` |
| 2026-10-31 | P1 | doctest test-case names never contain commas | `doctest_discover_tests(ADD_LABELS)` loses the label of such tests, which would silently drop them from `ctest -L unit` (and CI) | — |
